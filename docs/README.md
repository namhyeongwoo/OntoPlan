# Project page

Static site for GitHub Pages (Settings → Pages → deploy from branch, folder `/docs`). No build step: open `index.html`
or serve the folder (`python -m http.server -d docs`).

| Path | Content |
|---|---|
| `static/js/` | page scripts (scene graph, replays, charts, figures) |
| `static/data/` | data the scripts read, generated by `scripts/` |
| `static/images/`, `static/fonts/` | figures, icons, and the figure fonts (licenses in `static/fonts/README.md`) |

Regenerating the data:

| Script | Output | Input |
|---|---|---|
| `scripts/build_scene_graph.py` | `static/data/klickitat.js` | Klickitat world model in `world_model/data/envs/` |
| `scripts/build_hero_plans.py` | `static/data/hero_plans.js` | result files of `experiments/run.py` (Klickitat Small) |
| `scripts/build_task_replays.py` | `static/data/replays.js` | result files of `experiments/run.py` |
| `scripts/build_session.py` | `static/data/session.js` | a recorded multi-turn session |
| `scripts/build_figures.py` | `static/data/figures.js` | `figures/overview.pptx`, `figures/world_model.pptx` exported to SVG by LibreOffice |
